# Referencia complementaria para alpha

Schreider, M.; Scacchi, G.; Franco, F.; Fuentes, R.; Moreno, C. (2001).
Aplicación del método de Lischtvan y Lebediev al cálculo de la erosión general.
Ingeniería Hidráulica en México, XVI(1), 15–26.

Se consultó la publicación completa en línea. En la página impresa 16 (PDF 2),
ecuación 1, se define:

```text
alpha = Qd / (Hm^(5/3) * Be)
```

Be es el ancho superficial efectivo asociado al caudal; Hm es el tirante medio
antes de la erosión. La versión inicial utiliza únicamente la sección rectangular.
No se incorpora mu dentro de alpha: aparece una sola vez en la ecuación MTC.
No se adoptan de este artículo regresiones alternativas para beta o z.
